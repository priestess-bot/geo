## 2. 项目定位

本仓库已经从“智推时代 / GEO / GENO 调研文档”推进到 AU 首发 GENO SaaS MVP 的工程实现。当前核心方向是：

- 澳大利亚首发，优先做稳定可审计证据链，而不是先扩国内平台。
- 产品拆成两个入口：
  - 客户门户：给客户看单项目仪表盘、模块详情、启动配置、可解释性摘要和客户可见状态。
  - 内部项目中心：给运营/交付团队新建项目、配置启动参数、查看项目详情和工程状态。
- 旧 `apps/web` / `/ops` 暂时保留为遗留 Runtime Console 和迁移源，但默认 Docker 自动端口启动不再暴露它。
- 审计原则：所有关键输出尽量有 hash、source artifact、verifier、audit event 或 runtime access log，避免不可复盘的黑箱状态。

## 4. 启动方式

推荐用自动端口 Docker：

```bash
make docker-up-auto-ports
```

该命令会在 `18000-18249` 范围内为以下服务寻找空闲端口，并生成 gitignored 的 `tmp/docker-compose.auto-ports.env`：

- PostgreSQL
- MinIO API
- MinIO Console
- FastAPI API
- Customer Web
- Admin Web

关闭：

```bash
make docker-down-auto-ports
```

注意：直接 `docker compose -f infra/docker-compose.yml config` 会显示静态默认端口，例如 customer-web `3000`、admin-web `3001`。真正避免端口占用要通过 `make docker-up-auto-ports` 生成覆盖环境变量。
