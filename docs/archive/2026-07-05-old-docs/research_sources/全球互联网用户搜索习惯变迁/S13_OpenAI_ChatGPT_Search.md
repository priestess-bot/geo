# S13 OpenAI：ChatGPT Search

来源：OpenAI, Introducing ChatGPT Search

链接：https://openai.com/index/introducing-chatgpt-search/

来源类型：官方发布

访问日期：2026-06-08

## 关键内容

OpenAI 发布 ChatGPT Search，提供带相关网页来源链接的及时答案。该能力从付费和特定用户逐步扩展，2024 年 12 月扩展到登录用户，2025 年 2 月对可用地区所有用户开放。

## 本文使用方式

用于说明 AI 助手正式成为搜索入口之一，用户可以直接在对话中获得带来源的答案。

## 审计注意事项

- 产品能力和开放范围持续变化，引用时应注明日期。
- OpenAI 网页对命令行请求可能返回 403，但浏览器侧可访问。
