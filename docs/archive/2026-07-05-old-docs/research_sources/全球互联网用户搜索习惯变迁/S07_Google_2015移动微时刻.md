# S7 Google：移动微时刻与即时搜索

来源：Google Inside AdWords, New insights launched to help marketers

链接：https://adwords.googleblog.com/2015/06/new-insights-launched-to-help-marketers.html

来源类型：官方博客 / 营销研究

访问日期：2026-06-08

## 关键数据

- 82% 智能手机用户在寻找本地商家时会使用搜索引擎。
- 91% 智能手机用户在做任务时会用手机寻找想法。

## 本文使用方式

用于说明移动搜索不只是把桌面搜索搬到手机上，而是把搜索切碎成“现在就要知道、现在就要去、现在就要做、现在就要买”的微时刻。

## 审计注意事项

- 数据来自 Google/Ipsos 相关研究，营销场景较强。
- 适合作为移动搜索场景化证据，不宜作为全球全行业普遍比例。
