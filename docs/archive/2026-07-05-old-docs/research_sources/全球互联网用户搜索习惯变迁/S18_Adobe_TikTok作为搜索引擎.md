# S18 Adobe Express：TikTok 作为搜索引擎

来源：Adobe Express, Using TikTok as a search engine

链接：https://www.adobe.com/express/learn/blog/using-tiktok-as-a-search-engine

来源类型：消费者调查

访问日期：2026-06-08

## 关键数据

Adobe Express 报告称：

- 64% Gen Z 曾把 TikTok 当搜索引擎使用。
- 49% Millennials 曾把 TikTok 当搜索引擎使用。

## 本文使用方式

用于说明年轻用户会在短视频平台中寻找教程、体验、评价和灵感型信息，社媒搜索已经成为传统搜索之外的重要补充入口。

## 审计注意事项

- 这是调查数据，受样本和平台语境影响。
- 该结论不代表全球所有年龄段，也不代表所有搜索任务。
- Adobe 页面对命令行请求可能返回 000，但浏览器侧可访问。
