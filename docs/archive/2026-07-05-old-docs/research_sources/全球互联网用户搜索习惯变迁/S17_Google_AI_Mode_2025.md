# S17 Google：AI Mode

来源：Google Blog, AI Mode Search

链接：https://blog.google/products-and-platforms/products/search/ai-mode-search/

来源类型：官方博客

## 关键内容

Google 发布 AI Mode，提供更适合复杂问题、多步骤任务和追问式探索的搜索体验。

## 本文使用方式

用于说明搜索交互正在从一次关键词查询转向对话式、多步骤、可追问的答案探索。
