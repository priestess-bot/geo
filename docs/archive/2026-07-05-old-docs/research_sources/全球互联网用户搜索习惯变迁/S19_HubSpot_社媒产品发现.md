# S19 HubSpot：社媒产品发现

来源：HubSpot, social media product research / consumer trends

链接：https://blog.hubspot.com/marketing/social-media-product-research

来源类型：营销调查

访问日期：2026-06-08

## 关键数据

- 26% 消费者更偏好通过社媒发现新产品。
- 48% Gen Z 更偏好通过短视频平台发现新产品。

## 本文使用方式

用于说明产品发现和品牌认知不再只发生在搜索引擎，也大量发生在社交和短视频平台。

## 审计注意事项

- 数据适合消费品和营销场景分析。
- 不宜直接外推到所有 B2B、医疗、金融等高决策成本行业。
