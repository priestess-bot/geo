创作者经济 仅限美国

在您的平台上解锁创作者货币化方式

Stripe 可帮您快速实现全球创作者的入驻和提现。X、Substack 和 Clubhouse 等公司都已与 Stripe 合作，为创作者提供定制解决方案，在他们的平台上赚钱。

联系销售 

专为创作者经济打造

通过您的平台赋能创作者，开启盈利新范式

Stripe 的产品将技术、法务和合规相关的投入成本降到最低，使创作者能够轻松地在您的平台上赚取更多收入，让他们在分享内容和才华的同时接收来自世界各地的付款，帮助他们与粉丝建立更牢固的关系。您还可以通过发行信用卡和数字钱包来帮助创作者管理现金流。

售票

从线上对话到演唱会，创作者总是在寻找与粉丝互动的机会。通过售票，粉丝可以连线创作者，并为他们的时间和精力付费。

粉丝打赏

解锁您平台上的内容打赏功能，加强创作者与粉丝之间的互动。通过打赏创作者的创作内容来表达对他们的支持。

内容和会员订阅

允许创作者向粉丝开放会员和订阅，建立经常性的收入来源。创作者可以出售文字内容、播客、在线课程等。

金融服务

用我们的银行即服务 API（Treasury 和 Issuing）来提供资金管理账户，并向您平台上的创作者发行定制奖励卡。

开始

全球创作者入驻及打款的最简单方式

入驻新创作者并快速为其打款。充分利用我们的预构建 UI，更快启动并最大化转化率。通过 Stripe Connect 的全球支付路由和提现引擎，您可以为创作者定制您首选的打款计划，并指定您的每笔交易费用。

1

即时入驻全球创作者

快速入驻创作者，让他们只需回答几个问题即可开始收款和提现。Stripe Connect 提供本地化的入驻流程，并为您平台上的 Connect 子账户处理付款的 KYC 工作，帮助节省您团队的时间。

2

制定灵活的打款计划

设计一个最适合创作者的提现计划。提供滚动提现选项，甚至支持即时提现。Stripe 支持 135 种以上货币和稳定币，方便创作者进行跨境资金往来，且无需额外开销。

3

为创作者提供一个款项管理平台

Stripe Express 提供了一个预构建的管理平台，帮助创作者实时跟踪付款。创作者可以更好地了解自己的平台收入，更全面地了解他们的现金流。

平台差异化

为创作者经济打造的综合解决方案

Stripe 还提供其他集成选项，为您的创作者构建合适的解决方案。立即开始使用 Connect，轻松添加经常性订阅、快速结账等功能。

循环付款

使用 Stripe 的收入恢复工具，一次性或定期发送账单、管理订阅并减少支付拒绝率。

探索 Billing﻿ 

预构建的支付表单

简化付款信息的输入，允许支付信息重复利用，为顾客提供流畅顺滑的支付体验。

探索 Checkout 

嵌入式金融服务

发行虚拟卡和实物卡，便于创作者即时安全地获得资金，并且更好地管理线上、应用内或店内消费。

探索 Issuing 

管理您的平台

实现创作者平台中心化运营

Stripe 可以取代那些平常用来管理付款和提现、处理退款及自动生成税表的多个系统，让您能从一个完全整合的控制中心管理您的创作者平台，进行趋势分析、跟踪创作者账户等操作，将平台运营集中于一处。

管理创作者账户

使用 Stripe 管理平台创建、管理和更新创作者的账户。查看创作者账户的整个生命周期，包括历史记录、验证及转移。

简化报税

使用您的平台品牌自动生成 1099 税表（包括 1099-NEC、1099-MISC 和 1099-K）。获得税号验证帮助，以保持合规，避免罚款。

处理退款和争议

通过 Stripe 管理平台或 API 轻松处理退款和争议。快速响应客户并提交有效证据可帮您将损失保持在最低水平。

追踪收入

从中央管理平台了解您平台的收入。选择何时将资金转入您的银行账户并更新您的支付信息。

案例研究

借助 Stripe，Substack 的付费订阅量突破 500 万。

Substack 是一个全球媒体平台，提供视频、写作、播客和以创作者为中心的社区，拥有数千万活跃订阅者。其目标是帮助独立发布者建立、管理和变现其业务。

挑战

Substack 需要一种对发布者和订阅者都快速、顺畅的支付体验：提供灵活的支付选项、为发布者提供透明的交易数据，并具备强大的欺诈防护能力，同时还能合规地处理订阅者数据。

解决方案

Substack 从一开始就基于 Stripe 构建其支付系统，使用 Connect 来支持发布者提现，使用 Stripe Payments 和结账优化套件提供包括银行卡在内的 11 种支付方式，并通过 Stripe Billing 运行其订阅引擎。其成果包括：超过 5 万个活跃的付费出版物、透明可靠的提现（几乎无需工程维护），以及当订阅者保存了银行卡信息时，订阅转化率提升了 3 倍。

Stripe 让订阅和支付环节对所有参与者都变得非常简单。这有助于我们让写手和其他创作者在 Substack 上轻松创作并获得报酬。

Seth McMillan，工程经理

Teachable 通过 Stripe 帮助创作者赚取了 10 亿多美元

Teachable 赋能 10 万多名创作者、教练和企业，让他们得以制作线上课程来分享知识。到目前为止，通过 Stripe，Teachable 上的创作者已经创收逾 10 亿美元。

挑战

Teachable 使创建和销售在线课程和辅导服务变得容易。世界各地的创作者在平台上建立起了更大的业务，他们希望获得更多的支付功能和控制，在这种背景下，Teachable 需要一个灵活的支付解决方案，不仅能改善创作者的体验，还能推动收入增长。

解决方案

借助 Stripe Connect，他们仅用三名工程师就在三个月内推出了 Teachable Payments，创作者可通过它接受来自世界各地学生的付款，还可设置自定义提现计划，并简化管理任务。通过 Stripe，Teachable 的支付收入增长了 140%，同时还降低了欺诈率，简化了全球合规工作。
