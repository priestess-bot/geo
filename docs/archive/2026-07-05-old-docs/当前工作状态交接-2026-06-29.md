## 5. 当前启动方式

推荐启动整套服务：

```bash
cd /home/ymm/ym/gz/20260608-geo
make docker-up-auto-ports
```

该命令会自动寻找端口并启动：

- PostgreSQL
- MinIO
- FastAPI API
- Customer Web
- Admin Web
- Dashboard Web

终端会打印：

- `Customer Web`
- `Admin Web`
- `Dashboard Web`
- `API`
- `API docs`
- `MinIO API`
- `MinIO Console`
- `PostgreSQL`

单独启动 Dashboard Web：

```bash
cd /home/ymm/ym/gz/20260608-geo/apps/dashboard-web
npm ci
./node_modules/.bin/next dev -H 0.0.0.0 -p 3002
```

访问：

```text
http://localhost:3002
```

关闭整套自动端口服务：

```bash
make docker-down-auto-ports
```

## 7. 当前环境限制

本轮曾尝试启动本地 dev server，但当前 Codex 沙箱禁止监听端口，表现为：

```text
listen EPERM: operation not permitted
```

提权启动也被审批层拒绝，原因是审批请求通道异常。因此本轮未能在对话环境内提供一个实际运行中的浏览器访问 URL。代码层面已通过 typecheck、build、Compose config 和契约测试；用户本机正常 shell 下可按第 5 节命令启动。

另外，`make docker-auto-ports-config` 在当前沙箱中也会因 socket 创建权限受限失败：

```text
PermissionError: [Errno 1] Operation not permitted
```

这属于当前执行沙箱权限限制，不是 Makefile 逻辑失败。

## 8. 当前边界与注意事项

- Dashboard Web 是工程进展看板，不是客户门户、Admin 项目中心或运行时控制台。
- Dashboard Web 当前不请求 API、不依赖数据库、不依赖 MinIO。
- 数据由 `apps/dashboard-web/data/dashboard-data.json` 手动维护；后续如要自动生成，可再新增脚本。
- `GENO` 是当前产品/系统名，`GEO` 是业务类别。若需要对外更直观，可以在 UI 文案上补 `GEO`，但不建议轻易改 `GENO_*` 环境变量、headers、包名和内部命名。
- 旧 `apps/web` / `/ops` 仍保留为迁移源，不由默认自动端口启动暴露。
