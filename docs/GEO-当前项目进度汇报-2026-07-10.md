## 2. 知识库现状

### 2.1 导入与解析

已支持文件、粘贴文本、CSV、单 URL、URL 批次和站点抓取。输入经过格式、大小、私网 URL、重复对象和安全预检，再进入统一 GEO Adapter Output Contract。

已实际运行：

| 组件 | 实跑结果 | 关键产物 |
| --- | --- | --- |
| Docling | Pass | HTML/PDF、Block/Page/Table；离线模型初始化约 12 秒 |
| MinerU | Pass | PDF、OCR span、parser artifacts |
| Unstructured | Pass | 文档元素和正文 |
| MarkItDown | Pass | Markdown |
| Apache Tika | Pass | 正文与 metadata |
| Crawl4AI | Pass | HTML、Markdown、截图、链接图 |
| BGE-M3 | Pass | 本地模型、1024 维向量 |

模型权重从只读 `.cache/models` 挂载，不进入 Git。重组件和生产 worker 均启用 Hugging Face/Transformers 离线模式，避免本地模型已存在时仍等待外网超时。

### 2.2 编排、质量与版本化

完整编排对象包括 Pipeline Run、Stage、Import/Crawl/Parser/Chunk/Embedding/Fact/Prompt/Content Job。执行状态、审核状态和产物生命周期分离。

已验证：

- `reparse` 保留旧 Parser Run；
- `rechunk` 将旧 Chunk 标记为 superseded；
- `reindex` 不修改 Chunk 正文；
- `fact_refresh` 保留旧候选；
- Prompt/Content 重生成保留旧产物；
- `full_rebuild` 保留 Source Asset 并创建新版本产物；
- disabled/stale Chunk 不进入检索或生成；
- 事实、Prompt、文案必须经过人工审核；
- 生成结果必须能追溯到 approved fact、Chunk 和 Source Asset；
- security/traceability gate 不允许自动接受风险。

### 2.3 Prompt 与 GEO 文案

DeepSeek 用于事实抽取、Prompt 候选和 GEO 文案生成。候选经过审核后才能导入正式 Prompt 或导出内容。

本次测试发现模型可能生成有引用但正文省略品牌名，现已加入确定性业务约束：模型正文未出现目标品牌时，系统补充含品牌的一级标题，保留模型正文和 citation refs。修复后的完整 live pipeline 已再次 36/36 + 12/12 通过。

## 4. 本轮发现并修复的堵点

- Repository SQL 占位符和 AuditEvent 列拼接错误；
- CSV 知识事实状态触发数据库 500，改为 API 前置校验并使用正式 `active` 状态；
- Docker fallback worker 未收到 DeepSeek key，改为 stdin 注入且禁止泄漏；
- DeepSeek connector 输出截断，扩大 token 上限并报告 finish reason；
- PostgreSQL 初始化临时服务重启导致 migration 竞态，增加双重等待；
- Prometheus 指标名过期、首次 scrape 竞态；
- MinIO backup 镜像缺少 `cmp`，改为 SHA-256 对比并增加启动重试；
- Qdrant smoke 未读取自动端口文件；
- 基础设施测试硬编码 Prometheus/Grafana 端口；
- Docling 已有本地模型仍尝试联网，导致约 296 秒超时；
- DeepSeek GEO 文案偶发省略品牌名。
