## 1. 调研结论先行

智推时代是一家围绕 GEO（Generative Engine Optimization，生成式引擎优化）提供服务和 SaaS 产品叙事的早期公司。根据官网、融资聚合页、艾瑞行业报告和 PDF 自述，它的核心定位是：帮助品牌提升在 ChatGPT、Perplexity、Gemini、DeepSeek、豆包、Kimi、文小言等 AI 搜索/AI 问答平台中的可见性、推荐率和答案质量。

从公开材料看，智推时代具有以下特征：

- 公司实体较新。公开工商聚合信息显示，上海智推时代科技有限公司成立于 2025-05-12，统一社会信用代码为 `91310113MAEHJPYX6X`，法定代表人为陈缪喆。
- 商业叙事集中在 GEO。官网、PDF 和艾瑞报告均围绕 AI 搜索可见性、内容优化、信源优化、知识图谱和多平台监测展开。
- 公开资料有一定行业曝光。能检索到艾瑞《2026年GEO生成式引擎优化行业研究报告》中对智推时代 GenOptima 的案例页，也能检索到融资新闻和媒体采访/转载。
- 证据链中自述材料比例较高。官网、公司 PDF、部分行业报告案例页和营销稿高度依赖企业访谈或企业自述。融资、客户数量、全球办公节点、客户案例效果等信息，目前缺少足够强的独立第三方可验证材料。
- 技术方案目前更多是产品/服务架构叙事，而不是公开可审计的软件实现。PDF 提到了自研 GENO 系统、四大模块、AI 爬虫监控、知识图谱、多模态生成、一键发布和 API 集成，但未看到公开代码仓库、接口文档、系统演示或可独立验证的技术指标。

因此，对智推时代的当前判断应是：

> 智推时代是一个在 2025-2026 年快速包装和推进 GEO 服务的早期品牌，已经形成较完整的市场叙事、产品模块命名和交付流程，但公开证据更多支持“公司正在做 GEO 服务/产品化探索”，尚不足以完全验证其全球布局、客户规模、融资细节和 GENO 系统真实成熟度。

### 3.1 需要注意的时间线矛盾

公开工商聚合信息显示公司成立于 2025-05-12，但公司官网或相关页面中出现“2023 年布局生成式搜索优化方向”“200+ 客户”等叙述。两者不一定冲突，可能存在以下解释：

- 创始团队或前身业务早于公司主体成立。
- “布局”指团队方向，不一定指该公司法人实体成立。
- 200+ 客户可能包含创始团队过往项目、合作生态或更宽泛客户口径。

但在对外材料中，建议不要直接写成“公司自 2023 年成立并服务 200+ 客户”，除非补到更明确的工商、合同、客户名单或权威报道。

## 9. 技术能力审计

### 9.1 已能从公开材料确认的技术方向

公开材料一致指向以下技术方向：

- AI 平台回答采集。
- 多平台 AI 可见性监测。
- 用户意图分析。
- 品牌知识库/知识图谱。
- 内容生成和多模态适配。
- 信源漏洞扫描。
- 分发和复测闭环。

这些方向和 GEO SaaS 的合理技术路径基本一致。

### 9.2 尚未能公开确认的技术实现

本次未检索到以下材料：

- GENO 系统公开代码仓库。
- 开源许可证或开源版本下载页。
- API 文档。
- SaaS 登录试用入口。
- 系统后台操作演示。
- 真实监测数据样例。
- 评分算法白皮书。
- 第三方安全或性能测试报告。

因此，若要判断 GENO 系统是否已经成熟可用，应安排技术尽调或 Demo 验证，而不是只依据 PDF 和官网。

### 9.3 建议 Demo 验证清单

如果后续要评估是否合作或竞品对标，建议要求对方演示：

1. 创建一个新品牌项目。
2. 配置目标市场、语言、竞品和 AI 平台。
3. 批量导入 50-100 个 Prompt。
4. 真实采集 ChatGPT、Gemini、Perplexity、Google AI Overviews 或 DeepSeek 的回答。
5. 展示原始回答、截图、时间、地区、账号/匿名状态。
6. 自动解析品牌提及、推荐位置、引用源、负面描述和竞品共现。
7. 生成 GEO 分数，并解释评分公式。
8. 找到信源缺口并生成内容建议。
9. 发布或记录分发任务。
10. 7 天后复测并展示前后变化。

但从可审计角度看，后续如果要做合作、投资、竞品分析或技术复刻，需要继续补四类证据：

1. 工商和股权证据：国家企业信用、股权结构、融资工商变更。
2. 客户证据：授权案例、验收报告、优化前后截图和 Prompt 样本。
3. 产品证据：GENO 系统 Demo、接口文档、数据模型、评分算法。
4. 交付证据：真实项目周期、团队配置、成本结构、复测方法。

在没有这些材料前，建议把智推时代作为“GEO 服务产品化方向的参考样本”，而不是完全照搬其宣传口径。
