- 范围：runtime report read model；`report_exports`、`report_evidence`、`visibility_score_snapshots`、`answer_runs`、`prompt_questions`、`audit_events` 聚合查询；worker `--persist-analysis` 保存 M5 `ReportExport`；API/core tests；README/PLAN/worker README/前端状态同步。
- 代码落盘：
  - `packages/geno_core/geno_core/models.py`：新增 `RuntimeReportExport`、`RuntimeReportExportPage`。
  - `packages/geno_core/geno_core/repository.py`：新增 `list_runtime_report_exports()` 与 `_load_runtime_report_export()`，读回 report export、score snapshots、report evidence answer runs、report audit event，并嵌入 runtime citation graph。
  - `apps/api/geno_api/main.py`：新增 `/v1/reports/runtime`，缺少 `DATABASE_URL` 时返回 503；contracts 增加 runtime report types 和 endpoint。
  - `workers/collector_worker/run_collection_slice.py`：`--persist-analysis` 在保存 score 与 graph 后调用 `MarkdownCsvReportExporter` 生成 report snapshot 并保存 `ReportExport`、`ReportEvidence` 和 report audit event；输出 `report_export_id` 与 report evidence 计数。
  - `tests/test_core_contracts.py`、`tests/test_api_contracts.py`：新增 runtime report read model、runtime report 503 和 contracts 测试。
  - `README.md`、`PROJECT-PLAN.md`、`workers/collector_worker/README.md`、`apps/web/app/page.tsx`：同步 runtime report API 与 worker report snapshot persistence 状态。
