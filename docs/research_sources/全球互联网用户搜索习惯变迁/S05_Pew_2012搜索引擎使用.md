# S5 Pew Research Center：Search Engine Use 2012

来源：Pew Research Center, Search Engine Use 2012

链接：https://www.pewresearch.org/internet/2012/03/09/search-engine-use-2012/

来源类型：调研报告

访问日期：2026-06-08

## 关键数据

- 2012 年，美国在线成年人中 91% 使用搜索引擎。
- 59% 的美国在线成年人在任意一天使用搜索引擎。
- 搜索用户中，91% 表示总能或大多数时候找到所需信息。
- 搜索用户中，73% 认为找到的信息大多数或全部准确可信。
- 搜索用户中，83% 最常使用 Google。

## 本文使用方式

用于证明蓝链搜索在成熟互联网市场中已经成为日常入口，并且用户对搜索引擎建立了较高信任。

## 审计注意事项

- 样本是美国成年人，不代表全球。
- 该数据适合说明搜索主流化，不适合直接推断 2026 年全球行为。
