# S2 World Bank：全球互联网使用率

来源：World Bank Data / ITU 指标 `IT.NET.USER.ZS`

链接：https://data.worldbank.org/indicator/IT.NET.USER.ZS

来源类型：官方统计

访问日期：2026-06-08

## 关键数据

World Bank 指标显示，全球使用互联网人口占比大致变化如下：

| 年份 | 全球互联网使用人口占比 |
| --- | --- |
| 2005 | 15.6% |
| 2010 | 28.4% |
| 2015 | 39.9% |
| 2020 | 60.1% |
| 2023 | 69.2% |

## 本文使用方式

用于说明搜索习惯变迁的底层条件：互联网从少数人工具变成全球基础设施后，“找信息”才成为大规模日常行为。

## 审计注意事项

- 指标定义是过去 3 个月从任何地点、任何设备使用互联网的人口占比。
- 该数据不是搜索行为数据，而是搜索需求和数字行为的基础人口数据。
