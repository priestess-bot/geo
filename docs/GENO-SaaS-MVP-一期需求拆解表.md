# GENO SaaS MVP 一期需求拆解表

## 1. 一期目标

一期目标是完成 GEO 业务最小闭环：

```text
项目配置 -> 问题集 -> AI回答采集 -> 可见性评分 -> 知识库 -> 内容生成审核 -> 分发记录 -> 报表预警
```

一期优先保证可用、可解释、可复盘，不追求全平台自动化和复杂归因。

## 2. 角色定义

| 角色 | 说明 |
| --- | --- |
| 系统管理员 | 管理租户、平台、模型、全局配置 |
| 项目负责人 | 管理项目、成员、交付节奏和客户报表 |
| 数据分析师 | 配置问题集、查看监测结果、复核分析 |
| 知识库架构师 | 导入资料、审核事实、维护知识库 |
| 内容运营 | 生成内容、创建发布任务、回填发布结果 |
| 审核人 | 审核知识事实和内容资产 |
| 客户只读用户 | 查看项目看板和报告 |

## 3. 需求优先级

| 优先级 | 定义 |
| --- | --- |
| P0 | MVP 必须具备，没有则闭环不可用 |
| P1 | 一期重要能力，影响交付效率或客户体验 |
| P2 | 可延后能力，适合二期优化 |

## 5. MVP 里程碑

### M1：项目配置和问题集

目标：完成项目初始化能力。

范围：

- 租户/项目/品牌/竞品。
- 平台字典。
- 问题集管理。
- 角色权限基础能力。

验收：

- 能创建一个客户项目。
- 能配置至少 5 个平台、5 个竞品、100 个问题。

### M2：AI 监测和评分

目标：完成 GEO 基线评估。

范围：

- 手动/定时采集。
- 原始回答和证据保存。
- 自动解析。
- 可见性评分。
- 监测看板。

验收：

- 能跑完一次基线采集。
- 能输出平台对比、竞品对比和风险问题列表。

### M3：知识库和内容工作台

目标：完成从问题缺口到内容草稿。

范围：

- 文件导入。
- 文档解析。
- 事实抽取和审核。
- 内容生成。
- 风险检查。
- 内容审核。

验收：

- 能导入客户资料。
- 能形成 approved 事实。
- 能基于事实生成内容并通过审核。

### M4：分发任务和报表

目标：完成交付闭环。

范围：

- 分发任务。
- 发布链接回填。
- 周报/月报。
- 预警。

验收：

- 能记录发布动作。
- 能关联后续监测趋势。
- 能生成客户报告。

## 7. 建议研发排期

| 周期 | 重点 | 主要产出 |
| --- | --- | --- |
| 第 1-2 周 | 产品原型和数据模型 | PRD、原型、数据库设计、评分规则 |
| 第 3-5 周 | 项目配置、问题集、采集任务 | 项目后台、问题管理、采集任务框架 |
| 第 6-8 周 | 回答解析和看板 | 分析流水线、评分引擎、监测看板 |
| 第 9-11 周 | 知识库和内容工作台 | 文档导入、事实抽取、内容生成、审核 |
| 第 12-13 周 | 分发任务和报表 | 分发台账、周报/月报、预警 |
| 第 14 周 | 试点和修复 | 试点项目、问题修复、上线验收 |

## 8. 数据埋点与运营指标

| 指标 | 说明 |
| --- | --- |
| 采集成功率 | 成功采集问题数 / 应采集问题数 |
| 自动解析准确率 | 人工复核通过的解析结果比例 |
| 品牌提及率 | 提及品牌的问题比例 |
| 品牌推荐率 | 明确推荐品牌的问题比例 |
| 平均排名 | 品牌在列表回答中的平均位置 |
| 负面率 | 存在负面表达的问题比例 |
| 内容审核通过率 | 审核通过内容 / 提交审核内容 |
| 发布完成率 | 已发布任务 / 应发布任务 |
| 报表生成成功率 | 成功生成报表 / 应生成报表 |
| 单项目模型成本 | 项目维度 LLM 调用成本 |

## 9. 待确认问题

| 问题 | 建议 |
| --- | --- |
| 一期首批客户行业 | 选择教育、企业服务、跨境支付等资料较丰富且合规边界相对清晰的行业 |
| 首批 AI 平台 | 国内选 DeepSeek、豆包、Kimi；海外选 ChatGPT、Perplexity |
| 采集方式 | API 优先，其他平台先支持人工回填和半自动采集 |
| 报表格式 | 先做网页报表，再导出 PDF |
| 内容发布 | 一期只做任务和回填，不做违规自动发布 |
| 评分权重 | 默认权重上线，但必须允许项目级调整 |
